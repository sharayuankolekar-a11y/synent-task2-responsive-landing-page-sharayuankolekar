# SAVOR — Responsive Landing Page

SAVOR is a luxury personal chef booking service concept that brings restaurant-quality global dining experiences directly to users' homes.

## Features
- **Luxury Editorial Aesthetic**: Inspired by high-end hospitality brands and culinary magazines.
- **Global Culinary Focus**: Highlighting Indian, Japanese, Chinese, Italian, Thai, Mexican, and Middle Eastern gastronomy.
- **Fully Responsive**: Crafted with mobile-first grid and flexbox strategies (no frameworks used).
- **Pure CSS Animations**: Smooth hover transitions, editorial layout crops, and mobile drawer transitions.

## Tech Stack
- HTML5
- CSS3 (CSS Custom Properties, Flexbox, CSS Grid)
- Vanilla JavaScript (Used solely for mobile navigation toggling)
