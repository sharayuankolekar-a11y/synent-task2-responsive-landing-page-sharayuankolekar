# SAVOR – Project Report

## 1. Project Title

**SAVOR – Responsive Personalized Chef Landing Page**

## 2. Project Overview

SAVOR is a responsive landing page designed for a personalised chef service.

The concept behind the website is to provide customers with a premium dining experience in their own space by connecting them with personalised chefs.

The main focus of the project was to create an attractive landing page with a strong visual hierarchy while ensuring that the website remains usable across desktop, tablet, and mobile screen sizes.

## 3. Objective

The main objectives of SAVOR were:

* To create a modern landing page for a premium chef service.
* To create a strong and visually appealing hero section.
* To present the service's main features clearly.
* To practise responsive web design.
* To create layouts using modern CSS techniques.
* To ensure that the website adapts to different screen sizes.
* To improve practical knowledge of HTML, CSS, and JavaScript.

## 4. Technologies Used

* **HTML5** – Used to structure the landing page.
* **CSS3** – Used for styling, layout, responsive design, typography, and spacing.
* **JavaScript** – Used for interactive elements where required.

## 5. Main Features

The SAVOR landing page includes:

* Hero section.
* Premium personal chef service presentation.
* Service/features section.
* Call-to-action elements.
* Responsive page layout.
* Footer section.
* Modern visual design.
* Mobile-friendly structure.

## 6. Responsive Design

Responsiveness was an important part of this project.

The website was designed to adapt to different screen sizes rather than being limited to desktop displays.

CSS media queries were used to adjust layouts and element positioning for smaller screens.

Flexbox and CSS Grid were used where appropriate to create flexible layouts.

The responsive design approach helped ensure that content remained readable and usable on mobile, tablet, and desktop devices.

## 7. Development Process

The project began with the basic structure of the landing page using HTML.

The hero section was designed first because it provides the user's first impression of the service. Other sections were then added to communicate the features and value of the service.

CSS was used to create the visual style, including typography, spacing, layouts, buttons, and responsive behaviour.

JavaScript was used for interactive functionality where required.

The website was then tested at different viewport sizes and the layout was adjusted where elements did not behave as expected.

## 8. Challenges Faced

One of the main challenges was creating a layout that looked balanced on large screens while still working properly on smaller screens.

Some elements that worked well on desktop required different positioning or sizing on mobile.

Another challenge was maintaining visual hierarchy. The hero section, headings, features, and calls to action needed to be visually distinct without making the page feel cluttered.

## 9. Learning Outcomes

Through SAVOR, I improved my understanding of:

* Responsive web design.
* CSS Flexbox.
* CSS Grid.
* Media queries.
* Responsive typography and spacing.
* Landing page structure.
* Visual hierarchy.
* User interface design.
* Designing for different viewport sizes.

The project helped me understand that responsive design is not simply about reducing the size of elements. The layout itself may need to change depending on the screen size.

## 10. Testing

The website was tested at different screen widths to check:

* Navigation and page structure.
* Text readability.
* Section spacing.
* Image and content positioning.
* Button placement.
* Responsive layout behaviour.
* Mobile and desktop presentation.

Issues identified during testing were corrected through changes to the HTML and CSS.

## 11. Conclusion

SAVOR provided practical experience in designing and developing a responsive landing page.

The project helped me understand how visual design, responsive layouts, and front-end technologies can work together to create a polished user experience.

It also improved my confidence in using CSS layouts and designing interfaces that adapt to different devices.
